# Development & Research (DevAndRes)

This directory contains scripts and notebooks used for evaluating different AI models, testing retrieval strategies, and preparing evaluation datasets.

## Key Files

### `Evaluation_Embedding.py`
A comprehensive script to evaluate the performance of a embedding models. The embeddings are generated by Prepare_EvaluationData.py script.
*   **Functionality**: It runs search queries against a dataset and computes metrics like Precision, Recall, F1-Score, and MAP (Mean Average Precision).
*   **Usage**: Configure the `model_name`, `evaluationPath`, and `top_k` parameters in the `__main__` block and run the script.

### `Evaluation_Reranker.py`
Similar to the embedding evaluation but focuses on testing Reranking models (e.g., Cross-Encoders) to improve search results after the initial retrieval.

### `Prepare_EvaluationData.py`
Scripts to generate the embeddings of evaluation data using a given embedding model. The embeddings are then used by Evaluation_Embedding.py script.

### `test.ipynb`
A Jupyter notebook for interactive testing and prototyping of new features or models.

## Metrics

The evaluation scripts typically report:
*   **Precision**: How many of the retrieved results were relevant?
*   **Recall**: How many of the relevant results were retrieved?
*   **F1-Score**: Harmonic mean of Precision and Recall.
*   **MAP**: Mean Average Precision, taking into account the rank of relevant results.
